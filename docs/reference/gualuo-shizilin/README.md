## 5. 派生矢量文件

### 5.1 SVG（每页一份，坐标 = 纸面毫米）

| 文件 | 页面 | 路径数 | 体积 |
|---|---|---|---|
| `svg/JS-15-p17_corridor-gualuo-details.svg` | P17 建施-15 | 18,892 | 4.70 MB |
| `svg/JS-20-p22_sishixiaosa-ting-details.svg` | P22 建施-20 | 12,972 | 3.32 MB |

- `viewBox` 为纸面尺寸：**594.08 × 420.16 mm**（A2）。
- 坐标系：原点左上，x 向右、y 向下，单位 mm。
- **真实构件尺寸 = 坐标值 × 比例分母**（P17 为 ×15，P22 为 ×10）。
  例：H06 挂落净长 2520，在 SVG 中量得 168 mm（2520/15 = 168）。
- 线条为 `<path>`（`M/L/C/Z`），描边保留原线宽（已按 mm 缩放）；无 `<image>`、无 `<text>`。
- 阅读顺序即原图绘制顺序，可按 `fill/stroke` 区分实线/填充。

### 5.3 DXF（已评估移除）

2026-11-07 曾生成两页 DXF（真实尺寸、mm 单位、18,892 / 12,972 条多段线，合计 16 MB），
经评估后**已从仓库移除**，原因：

1. 该 PDF 由打印驱动（pdfFactory）生成，一条线常被拆成多段，转出的是上万条碎线，无法形成干净图层；
2. 文字在原文件即为曲线，DXF 里也只能是多段线轮廓，**不可编辑为文本**；
3. 单页 8–9 MB 的体量，对"叠图比对"之外的用途收益很低。

**如需重新生成**：`pip install ezdxf`（须装在项目 `.venv` 内），读取 `page.get_drawings()`，
先 `page.rotation_matrix` 转正、再按 `25.4/72 × 比例分母` 换算成真实 mm，逐条 `add_lwpolyline()` 写出；
贝塞尔按 10 段折线展平。比例可用图框校验：应为 8605.5 × 6084.6 单位（= 纸面 573.7 × 405.6 mm × 15）。
注意重新生成后仍受上述三点限制，不建议再入库。

## 6. 复现命令

```bash

```

600 dpi PNG 由 PyMuPDF 直接渲染（未落脚本，命令等价于）：

```python
import pymupdf
doc = pymupdf.open("docs/reference/gualuo-shizilin/shizilin-yiyuan-2024-06-construction-drawings.pdf")
pix = doc[16].get_pixmap(dpi=600, colorspace=pymupdf.csGRAY)   # 第 17 页
pix.save("docs/reference/gualuo-shizilin/png/JS-15-p17_corridor-gualuo-details_600dpi.png")
```

工具与版本：`pymupdf`（PyMuPDF，项目 `.venv` 内安装）；未使用 poppler / Inkscape / mutool。
本机无 `pdftocairo`、`mutool`、`inkscape`，所以走 PyMuPDF 的路径解析而非外部 CLI。
两页的 `/Rotate = 270`，脚本已用 `page.rotation_matrix` 把竖版原始坐标转回横版图面。

## 8. 使用约束（重要）

- 这是**维修保养工程的施工图**，尺寸属**设计复原值**，不等于原物实测值，与园内实际构件可能有偏差。
- 建模时**作参考，不作绝对真值**；外观还原的关键尺寸应以现场照片 / 实测复核。
- 只覆盖狮子林门厅、回廊、四时潇洒亭三处做法，**不能外推为"苏式挂落"通用范式**。
- `out/`、`ref/` 均被 gitignore；本目录是**唯一受版本管理的图纸存档**，修改请直接改这里。

## 9. 文件命名规则

```
<编号>_<构件>-<位置>-<总长>x<总高>_<比例>_<图号>-p<PDF页>.png
```

- `<编号>`：H01–H14，与第 7 节一一对应；整页图用 `H00_page-...`；对照页用 `H00b_contact-sheet-...`。
- 比例写作 `1-15`（用连字符避免文件名歧义）。
- 路径与文件名一律 ASCII，中文说明集中在 README。
- 派生文件命名：`<图号>-p<页>_<英文描述>.<svg|_600dpi.png>`。
