# 网师园美人靠：调研与选型建议

调研日期：2026-11-07
范围：网师园的亭、轩、榭、廊。其他园林只在明确标注时作为“做法参照”。
本轮只做调研，未改 `src/`、`web/` 的任何代码。

## 先说结论

网师园里能确认有美人靠（鹅颈椅／吴王靠）的，主要是三处：

1. **月到风来亭**：六角亭，三面临水，亭内临水各面设鹅颈靠。
2. **竹外一枝轩**：临水三间，临水面设“吴王靠坐槛”，就是坐面加一段外倾的短靠背。
3. **半山亭**：歇山半亭，西、南两面开敞，柱间有美人靠，宫式万川格。

另外，**濯缨水阁**临水一面是木坐槛栏杆，照片里有人坐着倚靠，形态和美人靠同类；但正式资料只写“木栏杆”，没有直接用“美人靠”这个词。因此算“同类做法”，不算百分之百确认。

**射鸭廊、小山丛桂轩、看松读画轩、殿春簃／冷泉亭**没有查到美人靠记录，按“没有”处理，不凑数。

## 一、逐处看

### 月到风来亭

- 形态：六角攒尖，三面临水，底部用黄石墩架起，高出水面约 2 m。
- 美人靠：亭内临水一侧，柱间设鹅颈靠（照片里可见沿开间分段，具体包几面需现场数）；坐面下是水磨砖矮墙，亭内为朱色裙板。
- 照片里能看到的：靠背是“通长顶枋 + 格条芯”，不是一整片弯板；每段止于柱，柱位就是分段的位置；坐面和成人膝高差不多。
- 资料依据：导游词写“亭内设鹅顶靠”（应为鹅颈靠）；苏州市园林局写“亭榭柱间下部有时设鹅颈椅”。
- 一个小的表述冲突：苏州市园林局的匾额页把亭写成“八角”，但照片和多数资料是六角。本文按六角记录，现场可以再数一次。

### 竹外一枝轩

- 形态：卷棚硬山，东西狭长三间，临水开敞。
- 美人靠：临水面设“吴王靠坐槛”，导游词称“鹅项形短栏”。照片里是万字／宫式万川格芯，坐板压在石基上，端头抱柱。
- 这是三处里最适合直廊参照的一处：坐面高度和廊子现有坐槛几乎一样，只是多了一段外倾靠背。

### 半山亭

- 形态：歇山顶，南北约 4.5 m、东西约 3.6 m，西、南两面开敞，东、北两面为墙；门洞分别通女厅和射鸭廊。
- 美人靠：西、南两面柱间设美人靠，宫式万川格芯。外部文章里的照片，前景就是它的靠背。
- 尺寸和“两面开敞”的说法来自百科，建议现场复核；照片是外部链接，未复制入项目。

### 濯缨水阁

- 形态：卷棚歇山，三面墙、一面木栏，架空水上。
- 临水一面是木坐槛栏杆，照片里有人坐在上面倚靠；但正式资料只写“临池廊间置木栏杆”，没有写“美人靠”。
- 结论：做法同类，可以参照；用词上不要直接说“濯缨水阁的美人靠”，说“木坐槛栏杆”更稳。

### 没有确认的

- **射鸭廊**：单间短廊，北通竹外一枝轩、南连半山亭；没有查到美人靠记录，不单列方案。
- **小山丛桂轩、看松读画轩、殿春簃／冷泉亭**：没有查到美人靠记录，按“没有”处理。

## 二、网师园的做法，拆成六件事

| 事项 | 网师园看到的 | 可信度 |
|---|---|---|
| 坐面高度 | 约 0.42–0.45 m，和成人膝高相当 | 照片判断 + 通行做法，非实测 |
| 坐面进深 | 约 0.35–0.45 m | 通行做法，非实测 |
| 靠背形态 | 框架 + 格条芯；上枋／中枋／下枋 + 边梃，顶枋兼扶手；边梃做鹅颈形，靠背整体向外倾 | 苏州市园林局文字 + 照片；边梃细节来自木作行业资料，不是网师园测绘 |
| 后仰 | 资料只写“向外倾斜而微微弯曲”；木作常见 10–15° | 有文字描述，无实测角度 |
| 下部 | 月到风来亭：水磨砖矮墙 + 木坐板；竹外一枝轩／濯缨水阁：木坐槛压在石／砖基上；照片里未见悬空雕花牙板 | 照片 + 资料 |
| 与柱交接 | 边框两端底部开浅榫与坐板结合；两端箍头用铜／铁搭钩系柱 | 苏州市园林局原文 |
| 转角 | 按开间分段，端头止于柱；亭子转角由角柱断开，不做整圈连续弯木；顶枋是否绕柱做弯头，照片看不清 | 照片 + 推断，需现场复核 |

一句话概括：**网师园的美人靠是“坐面 + 外倾格条靠背”的组合，不是整片弯板；靠背在柱位分段，端头用榫和铁钩跟柱子连接；坐面下面要么是砖石矮墙，要么是木坐槛，没有看到悬空牙板。**

## 三、和本项目廊子的差别

本项目廊子的内圈坐槛在 [`src/world/buildings-corridor.js`](../../../src/world/buildings-corridor.js) 的 `body()` 里（第 49–56 行）：下枋 + 直棂 + 上枋，上枋顶面约高出廊地面 0.47 m，只有坐面，没有靠背。

| | 本项目廊子 | 网师园美人靠 |
|---|---|---|
| 总高 | 约 0.47 m（只有坐面） | 约 0.85–0.9 m（坐面 + 靠背） |
| 靠背 | 没有 | 外倾格条，顶枋兼扶手 |
| 格芯 | 直棂 | 万字／竖棂 |
| 下部 | 直棂 + 上下枋，直接坐在台明上 | 坐板 + 水磨砖矮墙，或木坐槛 |
| 柱交接 | 通长到柱边 | 端头抱柱 + 铁钩 |
| 用法 | 可坐、可挡 | 可坐、可倚 |

差别不在“有没有栏杆”，而在**靠背**：现有廊子做到坐面就停了，人只能坐、不能靠；网师园在坐面上又加了一段向外弯的格条靠背。

## 四、三个方案

### 方案一：竹外一枝轩式（直廊首选）

- **一句话**：保留现在的坐槛，只在上面加一段外倾的万字靠背。
- **适合位置**：直廊、长廊的临水／临园一侧。
- **尺寸建议**：坐面不动（约 0.47 m）；靠背顶 0.85–0.9 m；靠背自身高 0.38–0.43 m；外倾 10–12°；芯子用宫式万川或竖芯；端头抱柱。
- **为什么值得照做**：改动最小，和现有廊子的红木色、直棂尺度不冲突；照片证据也最完整。
- **不要照搬**：白墙、石基座。

### 方案二：月到风来亭式（临水亭／水榭）

- **一句话**：坐面下做砖石矮墙，上面铺木坐板，再加格条靠背。
- **适合位置**：临水亭、水榭、池岸节点。不建议用在轻巧的直廊，砖墙会显得重。
- **尺寸建议**：矮墙到 0.45 m，坐板面 0.45 m，靠背顶 0.85–0.9 m；格条芯；端头抱柱。
- **为什么值得照做**：下部实、防溅水、临水更稳；亭子里按开间绕一圈最自然。
- **不要照搬**：如果廊子下面是空的木构，不要做砖墙。

### 方案三：半山亭式（亭子转角／两面开敞）

- **一句话**：按开间分段，角柱收头，万字格，不做整圈弯木。
- **适合位置**：亭子周边、转角、L 形连接处。
- **尺寸建议**：同方案一；转角处两段各自抱柱，端头做鹅颈边梃；不要试图用一根通长弯木绕角。
- **为什么值得照做**：施工和建模都简单，转角不会出现“接不上”；半山亭就是西、南两面开敞、角柱收头的实例。
- **注意**：半山亭尺寸来自百科，照片是外部链接，落地前复核。

## 五、如果给本项目用，具体落点

- **代码位置**：`src/world/buildings-corridor.js` 的 `body()`，第 49–56 行的内圈坐槛。
- **方案一最小改动**：保留 `Y_PL + 0.44` 的坐面和下枋，往上加靠背；每开间按 `L_in` 生成；端头留 `COL_R` 抱柱；外倾 10–12°；不要把靠背做成整片板。
- **不建议这轮直接改**：廊子那边正在改檐口，且要守住 51 帧基准。后续建议用开关（例如 `?meirenkao=1`）对照，默认路径不变。
- 这轮只做调研，未动 `src/`、`web/`。

## 七、还没确认的

- 月到风来亭“六角／八角”的官方表述冲突。
- 濯缨水阁是否正式叫“美人靠”。
- 坐面／靠背的实测尺寸、后仰角度、转角弯头做法——没有公开测绘数据，需现场量。
- 半山亭的尺寸来自百科，未实测。

## 八、现场复核清单（如果去网师园）

- 坐面高：从地面到坐板面。
- 坐面深。
- 靠背顶高、靠背自身高。
- 靠背外倾角度、顶枋挑出坐面的距离。
- 坐面下是砖墙、木坐槛，还是牙板。
- 端头与柱的连接：榫、铁钩、抱柱，还是钉。
- 转角：顶枋是否绕柱、有没有弯头、两段是否共用一个边梃。
- 亭子里美人靠包了几面（月到风来亭重点数）。
